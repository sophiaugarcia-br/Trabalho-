# Finanças Universitárias (PUCPR - Raciocínio Algorítmico)

Sistema web local para controle financeiro universitário desenvolvido em Python com Flask e SQLite.

1. Clone o repositório e abra no PyCharm (ou VS Code).
2. Crie e ative o ambiente virtual (`venv`).
3. Instale as dependências:
   ```bash
   pip install -r requirements.txt
