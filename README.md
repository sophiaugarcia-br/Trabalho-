# Finant - Projeto final da disciplina de raciocínio algorítmico

Site de gerenciamento de finanças voltado a estudantes universitários, possibilitando a visualização e controle monetário de acordo com as entradas e saídas.

> Status: em desenvolvimento.

## Objetivo
Ajudar o usuário a gerenciar melhor sua renda, de modo a controlar gastos e providenciar uma melhor conscientização financeira.

## O que já foi feito
- Rascunho inicial do código em Python;
- Estruturação inicial do visual do site, incluindo CSS, HTML e uma parte de JS;
- Criação de gráfico estilizado e dinâmico para visualização lúdica de gastos.
